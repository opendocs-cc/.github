# Security

Please report vulnerabilities in OpenDocs (the website, API, CLI or exports)
privately to hello@opendocs.cc. For the CLI you can also use GitHub's
**Report a vulnerability** button on
[opendocs-cli](https://github.com/opendocs-cc/opendocs-cli/security). Don't open
a public issue for a security problem.

Include what you found and how to reproduce it. We'll reply as soon as we can
and keep you posted until it's fixed.
