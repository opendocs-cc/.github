# opendocs-cc/.github

The public profile for the [OpenDocs](https://opendocs.cc) organization on
GitHub. [`profile/README.md`](profile/README.md) is what you see on
[github.com/opendocs-cc](https://github.com/opendocs-cc).

The code lives in [opendocs](https://github.com/opendocs-cc/opendocs), and the CLI in
[opendocs-cli](https://github.com/opendocs-cc/opendocs-cli).
